# 产品需求：Serial Terminal

## 目标

提供一个轻量、可靠的 Windows 串口调试助手，用于查看串口数据、发送测试数据和保存通信记录。

## 约束

- 使用 Flutter 开发 Windows 桌面应用。
- 本机使用 Visual Studio Code 编写代码，不安装 Flutter SDK。
- GitHub Actions 在 Windows runner 上完成依赖安装、测试、构建和产物上传。
- 第一版优先支持单个串口连接和常见调试操作。

## MVP 功能

1. 枚举和刷新串口。
2. 配置串口、波特率、数据位、校验位、停止位和流控。
3. 打开、关闭串口并显示状态。
4. 接收文本或 HEX 数据。
5. 发送文本或 HEX 数据。
6. 显示时间戳、清空日志和自动滚动。
7. 发生串口错误时在日志区显示可读信息。

## 后续功能

- 数据位、校验位、停止位、流控的完整配置。
- 发送结束符支持无、CR、LF 和 CRLF。
- 发送换行符、快捷命令和循环发送。
- 通信日志导出。
- 多串口连接和协议解析。
- MSIX 或安装程序打包。

## 验收标准

- CI 能完成 Windows Release 构建。
- 连接真实串口后能接收和发送数据。
- HEX 模式不会改变原始字节。
- 断开连接后资源被释放，重复连接不会创建重复读取流。
- 失败场景有明确提示，不能静默丢失。
